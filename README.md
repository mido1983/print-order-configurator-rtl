# Print Order Configurator RTL for WooCommerce

RTL-first WooCommerce plugin for structured print order intake in Hebrew environments.

This plugin collects production options, design workflow choices, customer instructions, and uploads. It is intentionally not a visual product designer, canvas editor, PDF renderer, or Canva clone.

## Status

MVP implementation in progress. See `TASK.md` for the implementation plan and acceptance criteria.

## MVP Features

- Product-level print options.
- RTL Hebrew storefront configurator.
- Ready-design and design-service workflows.
- Upload validation for print/design assets.
- Cart, checkout, and order metadata.
- Admin order panel with protected file downloads.
- Optional design service fee.

## Requirements

- PHP 8.1+
- WordPress 6.5+
- WooCommerce 8.0+
